# Yandex STEP · 3DM Görüntüleyici

Yandex Disk paylaşım bağlantısını yapıştırın; altındaki STEP / IGES ve Rhino (.3dm) dosyaları tarayıcıda 3B açılır.
Bilgisayardaki dosyalar pencereye sürüklenip bırakılarak da açılır.
Dosyalar Yandex'ten doğrudan tarayıcıya iner ve orada okunur (STEP: OpenCascade WASM, 3DM: McNeel rhino3dm WASM); hiçbir sunucuya yüklenmez.
Rhino dosyalarında katmanlar açılıp kapatılır, bloklar adıyla sayılır; görüntüleme ağı olmayan ("Save Small") dosyalar tarayıcıda örülür.

Okyanus Grup — iç kullanım aracı.
